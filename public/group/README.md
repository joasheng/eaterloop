# Group photos

Drop group photos in this folder and they appear automatically—no code changes.

- Formats: `.jpg`, `.png`, `.webp`, `.gif`, `.avif`
- **Landing polaroid strip** and **Home "Everyone at the table" banner** use every photo here, in alphabetical order (prefix with `1-`, `2-`, … to control the order).
- **Preview-mode avatars:** name a file after a member (lowercased display name) to use it as their avatar across the app—e.g. `maya.jpg` → Maya's avatar. In production, avatars come from each member's own upload in Settings instead.

Files here are public. Keep anything private out of this folder.
